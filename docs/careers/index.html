Perception EngineerGroningen · on sitePerception+

Help vessels understand what is around them. Build perception that works with the glare, reflections, fog and changing light of inland waterways.

  • Python
  • Computer vision
  • Model evaluation
  • Sensor fusion

What you will work on

  • Develop detection, segmentation and tracking across camera and radar observations.
  • Build datasets and evaluate performance in glare, reflection, fog and changing light.
  • Connect perception outputs to the onboard world model, accounting for latency and uncertainty.

Core technical skills

  • Computer vision fundamentals: image geometry, calibration, object detection and tracking.
  • Machine learning practice: training and validation splits, metrics, overfitting and error analysis.
  • Numerical reasoning with arrays, probability and noisy sensor measurements.

Coding experience

  • Hands-on Python experience building and evaluating a perception or machine learning pipeline.
  • Experience with tools such as NumPy, OpenCV and PyTorch, or comparable libraries.
  • Readable, testable code; Git workflows; reproducible experiments; and confidence debugging on Linux.

Useful additional experience

  • C++ for performance-sensitive components; GPU inference or model optimisation.
  • Camera/radar fusion, multi-object tracking, robotics or edge deployment.
  • A project showing how you measured accuracy, handled a failure case and improved the result.

Distributed Systems EngineerGroningen · on sitePlatform+

Build the infrastructure connecting vessel intelligence to the wider fleet. Make observations and model updates useful even when a connection is intermittent.

  • Backend engineering
  • Networking
  • Data pipelines
  • Reliability

What you will work on

  • Design observation and state pipelines between vessels and shore.
  • Handle synchronisation, versioned state and recovery when connections drop.
  • Build monitoring and diagnostics that make failures understandable and recoverable.

Core technical skills

  • Distributed systems fundamentals: consistency, concurrency, retries and idempotency.
  • Networking, API design, message processing and the tradeoffs of different storage models.
  • Reasoning about throughput, latency, resource limits and partial failure.

Coding experience

  • Experience building a backend service in a language such as Go, Rust, Python, Java or C++.
  • Practical use of automated tests, Git, Linux and debugging tools.
  • Experience designing APIs and working with databases or queues; confidence profiling and investigating failures.

Useful additional experience

  • Containerisation, CI/CD, observability and operating services in production.
  • Offline-first systems, event streaming, schema evolution or time-series/geospatial data.
  • A project showing how you handled a failure, tested recovery or improved reliability.

Geospatial / SLAM EngineerGroningen · on siteWorld model+

Turn repeated passages into a persistent map of the waterway. Work on the geometry, localisation and mapping that connect individual observations across time.

  • C++ / Python
  • SLAM
  • Spatial geometry
  • State estimation

What you will work on

  • Develop localisation and mapping from positioning and perception observations.
  • Align repeated passages in a consistent georeferenced frame and detect meaningful changes.
  • Represent infrastructure, navigable space and uncertainty for downstream systems.

Core technical skills

  • Linear algebra, 3D geometry, coordinate transforms and reference frames.
  • State estimation, probabilistic reasoning and numerical optimisation.
  • Understanding of localisation, mapping, data association and sensor calibration.

Coding experience

  • Practical C++ or Python experience implementing and evaluating spatial algorithms.
  • Experience with numerical or geometry tools such as NumPy, Eigen, OpenCV or equivalent libraries.
  • Ability to test transforms and estimation logic, debug sensor data and compare results with a reference.

Useful additional experience

  • ROS/ROS 2, point clouds, GNSS/IMU fusion or geospatial data formats.
  • Pose graphs, bundle adjustment, loop closure or map change detection.
  • A project showing how you evaluated localisation accuracy, drift or uncertainty.
